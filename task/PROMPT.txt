做 proofcask，离线比对两批审计封存清单。每份清单用明确的规范 UTF-8 JSON 编码、叶子与内节点分域 SHA-256 描述一个载荷树。两批可以有不同树形；叶子 ID 稳定，存在同摘要不同证物的合法情况。路径重命名依赖有签收的映射记录，更正可在后来撤销映射。缺少中间节点、重复证物或同摘要但元数据不同都要分开处理。只根据可复核证据断言相同，允许输出不确定。
实现 reconcile OLD NEW MAP 输出新增、缺失、等价、冲突及相应的最小可复核路径。另实现 capsule INCLUDE REF，把多个指定证物和两份根之间的差异压缩为共享节点证明，按规范顺序输出，复核器独立确认每个证物及未包含对象不可被冒充。输入中有合法共享子树，有一方中间树缺页，也有路径改名但根里另一份同摘要叶仍存在。用变异测试逐一篡改证明顺序、树位置、叶 ID 与摘要，建立可读的错误区分。
从空仓库开始，在 Windows 普通 CPU 上用 Python 3.12 标准库交付。命令输出 UTF-8 JSON，附 README、合成夹具和可直接运行的 unittest。
